# CodeAlpha Stock Trading Platform

## Project Description
A console-based Java application that simulates a simple stock trading platform.

## Features
- Display available market stocks and prices
- Buy stocks
- Sell stocks
- Track stock holdings
- Calculate current portfolio value
- Calculate total profit/loss
- View transaction history
- View user details and account balance

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- ArrayList
- HashMap
- Console-based interface

## Project Structure
- `Stock.java` - Stores stock information
- `User.java` - Manages user details and balance
- `Transaction.java` - Records buy and sell transactions
- `Portfolio.java` - Manages stock holdings and portfolio performance
- `StockTradingPlatform.java` - Main application and menu

## How to Run

Compile all Java files:

```bash
javac *.java
Run the application:

java StockTradingPlatform
